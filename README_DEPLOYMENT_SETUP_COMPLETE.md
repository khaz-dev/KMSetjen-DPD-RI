## 🚀 How to Use Each Script

### Windows Users (deploy.ps1)

**Quick Start:**
```powershell
cd "d:\Project\KMSetjen DPD RI"
.\deploy.ps1 -Environment development
```

**All Options:**
```powershell
# Development (fastest, debug enabled)
.\deploy.ps1 -Environment development

# Staging (production-like, debug allowed)
.\deploy.ps1 -Environment staging

# Production (full safety, requires confirmation)
.\deploy.ps1 -Environment production

# Advanced combinations
.\deploy.ps1 -Environment development -BuildOnly
.\deploy.ps1 -Environment staging -NoPull
.\deploy.ps1 -Environment production -SkipBackup
```

### Linux/Ubuntu Users (deploy.sh)

**Quick Start:**
```bash
cd /path/to/project
chmod +x deploy.sh
./deploy.sh development
```

**All Options:**
```bash
# Development (fastest, debug enabled)
./deploy.sh development

# Staging (production-like, debug allowed)
./deploy.sh staging

# Production (full safety, requires confirmation)
./deploy.sh production

# Advanced combinations
./deploy.sh development --build-only
./deploy.sh staging --no-pull
./deploy.sh production --skip-backup
```
