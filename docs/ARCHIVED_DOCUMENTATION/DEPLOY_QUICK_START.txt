## ❓ If Something Goes Wrong

### Problem: SSH Connection Failed
```
Error: "Cannot connect to server"
Solution: Check SSH key path and server IP
```

### Problem: .env.staging not found
```
Error: ".env.staging not found"
Solution: Make sure .env.staging exists in d:\Project\KMSetjen DPD RI\
```

### Problem: Deploy script failed
```
Solution 1: Check server has docker-compose installed
Solution 2: SSH manually and run: sudo ./deploy-master.sh staging --verbose
Solution 3: Check server disk space: df -h
```
