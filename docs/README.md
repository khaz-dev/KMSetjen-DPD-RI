## Architecture Overview

**Django Apps:**
- `core` - User authentication and roles
- `content` - Articles, categories, tags
- `audit` - Audit logging
- `auth` - Authentication endpoints (SSO-ready)
- `api` - REST API (v1/public, v1/internal, v1/admin)

**Key Features:**
- Bilingual content (Indonesian/English)
- Role-based access control (5 levels)
- Content workflow (Draft → Review → Publish)
- Immutable audit trail
- PostgreSQL full-text search
- JWT + Session authentication

## Models Implemented

### Authentication (core/models.py)
- **User** - Government staff with NIP, department, SSO support
- **Role** - 5 roles: ADMIN, EDITOR, CONTRIBUTOR, READER, PUBLIC
- **Language** - Bilingual: id, en

### Content (content/models.py)
- **Article** - Bilingual articles with versioning and access control
- **Category** - Hierarchical categories
- **Tag** - Article tags with usage tracking
- **File** - Article attachments
- **ArticleVersion** - Revision history

### Audit (audit/models.py)
- **AuditLog** - Immutable audit trail for compliance

## API Structure

```
/api/v1/
├── public/         No auth required
│   ├── articles/
│   ├── categories/
│   └── tags/
├── internal/       Auth required
│   ├── articles/   (CRUD)
│   └── dashboard/
└── admin/          Admin only
    ├── users/
    ├── roles/
    └── audit-logs/

/api/auth/
├── token/          Get JWT token
├── token/refresh/  Refresh token
└── me/             Current user
```

## Environment Variables

Key variables in .env:
- `DJANGO_ENV` - dev/prod/test
- `SECRET_KEY` - Django secret key (generate new)
- `DEBUG` - True for development, False for production
- `DATABASE_URL` - PostgreSQL connection string
- `ALLOWED_HOSTS` - Comma-separated allowed hosts
- `CORS_ALLOWED_ORIGINS` - Frontend URLs
- `JWT_ACCESS_TOKEN_LIFETIME_HOURS` - Default: 1
- `JWT_REFRESH_TOKEN_LIFETIME_DAYS` - Default: 7
- `SSO_ENABLED` - Enable SSO (optional)
- `SSO_URL` - SSO provider URL (optional)

See `.env.example` for full list.

## Production Deployment

For production (Linux + Nginx + Gunicorn):

```bash
# Install production dependencies
pip install gunicorn

# Create .env.prod with production settings
# DEBUG=False
# ALLOWED_HOSTS=yourdomain.com
# CSRF_TRUSTED_ORIGINS=https://yourdomain.com

# Collect static files
python manage.py collectstatic --noinput

# Run with Gunicorn
gunicorn config.wsgi:application --bind 0.0.0.0:8002
```

## Troubleshooting

**Database connection error:**
- Check DATABASE_URL in .env
- Verify PostgreSQL is running
- Create database: createdb kms_setjen

**Secret key not set:**
- Generate: python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
- Add to .env: SECRET_KEY=<generated-key>

**Import errors:**
- Activate virtual environment: source venv/bin/activate
- Reinstall: pip install -r requirements.txt

**Port 8002 already in use:**
- Use different port: python manage.py runserver 0.0.0.0:8002
