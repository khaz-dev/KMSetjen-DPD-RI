## Getting Started

### Logging In
1. Navigate to the login page
2. Enter your username or email
3. Enter your password
4. Click "Login"
5. If 2FA is enabled, enter the verification code

### Dashboard Overview
After logging in, you'll see your dashboard with:
- **Recent Articles:** Your 5 most recently created articles
- **Stats:** View count, approval status overview
- **Quick Actions:** Create article, view drafts, see pending reviews

### User Roles
- **Admin:** Full system access
- **Editor:** Can create, edit, and publish articles
- **User:** Can create and view articles
- **Guest:** Can only view published articles

## Creating & Publishing Articles

### Step 1: Start New Article
1. Click **"Create Article"** button
2. You'll be taken to the editor
3. The article is automatically saved as draft

### Step 2: Fill Article Details
1. **Title:** Give your article a clear, descriptive title (required)
2. **Category:** Select from dropdown (required)
3. **Excerpt:** Brief summary (recommended, 50-150 words)
4. **Slug:** URL-friendly version auto-generated from title

### Step 3: Write Content
1. Use the **rich text editor** for formatting
2. **Keyboard shortcuts:**
   - `Ctrl+B` or `Cmd+B`: Bold
   - `Ctrl+I` or `Cmd+I`: Italic
   - `Ctrl+U` or `Cmd+U`: Underline
   - `Ctrl+L` or `Cmd+L`: Link
3. **Insert elements:**
   - Click **Image** button to add images
   - Click **Link** button to add hyperlinks
   - Click **Quote** button to add blockquotes

### Step 4: Format Your Article
- **Headings:** Use H1-H6 tags
- **Lists:** Use bullet or numbered lists
- **Blockquotes:** For citations
- **Code blocks:** For technical content

### Step 5: Preview
1. Click **"Preview"** button
2. See how article will appear to readers
3. Make adjustments as needed

### Step 6: Save & Submit
1. Click **"Save as Draft"** to save without publishing
2. OR click **"Submit for Review"** to send to editors
3. Article will be in **Pending** status

### Publishing Workflow
1. **Draft:** You created it, not yet reviewed
2. **Pending Review:** Submitted, waiting for editor approval
3. **Approved:** Editor approved, ready to publish
4. **Published:** Live and visible to all users
5. **Rejected:** Editor needs revisions (feedback provided)

## Managing Your Dashboard

### Editor Dashboard Features

#### Article Management
- **View All Articles:** See all your articles
- **Filter by Status:**
  - Draft (personal only)
  - Pending Review
  - Published
  - Rejected
- **Search:** Find articles by title or keyword
- **Sort:** By date, title, or view count

#### Article Actions
1. **Edit:** Click article to edit
2. **View:** See published article
3. **Delete:** Permanently remove (draft only)
4. **Submit:** Send draft for review
5. **Withdraw:** Remove from review (if pending)

#### Statistics
- **Total Articles:** All articles you've created
- **Published Count:** Live articles
- **Total Views:** Combined views across all articles
- **Average Views:** Per article average
- **Pending Reviews:** Waiting for approval

### Notifications
- **Article Approved:** When editor approves your article
- **Article Rejected:** With feedback from editor
- **New Comment:** When someone comments on your article

## Searching & Filtering Articles

### Using Search
1. Click **search icon** at top
2. Type keywords, title, or author
3. Results update as you type
4. Press Enter for full search

### Advanced Filters
1. **By Category:** Select from dropdown
2. **By Status:** Draft, Published, Pending
3. **By Date:** Last 7 days, 30 days, custom range
4. **By Author:** Filter articles by specific author

### Search Tips
- Use **quotes** for exact phrases: `"climate change"`
- Use **minus** to exclude: `-opinion`
- Search is **case-insensitive**
- Searches **title** and **content**

## Tips & Best Practices

### Writing Quality Articles
1. **Use Descriptive Titles**
   - Clear and concise
   - Front-load important info
   - Avoid clickbait

2. **Write Compelling Excerpt**
   - Summarize main points
   - Encourage readers to click
   - 50-150 words

3. **Structure Content**
   - Use headings to organize
   - Keep paragraphs short
   - 3-4 sentences per paragraph

4. **Include Images**
   - Use relevant images
   - Keep file sizes reasonable
   - Add alt text for accessibility

5. **Use Proper Grammar**
   - Proofread before publishing
   - Use consistent terminology
   - Check for spelling errors

### SEO Best Practices
1. **Use keywords naturally**
2. **Include keyword in title**
3. **Write descriptive excerpt**
4. **Use heading hierarchy (H1-H6)**
5. **Add internal links**
6. **Optimize image alt text**

### Content Guidelines
1. **Originality**
   - Write original content
   - Cite sources
   - Give credit to others

2. **Accuracy**
   - Fact-check claims
   - Provide sources
   - Update outdated info

3. **Appropriateness**
   - Avoid offensive language
   - Keep content professional
   - Follow community standards

## Frequently Asked Questions

### Can I edit a published article?
Yes! You can:
1. Click the article
2. Make changes
3. Click "Update"
4. Changes appear immediately

### How long does review take?
- Usually 24-48 hours
- Complex articles may take longer
- You'll receive email notification

### Can I delete a published article?
Only admins can delete published articles. You can:
- **Unpublish** it (removes from public view)
- **Archive** it (marks as archived)

### What if my article is rejected?
1. Check feedback from editor
2. Make requested changes
3. Resubmit for review
4. Contact editor if unclear

### Can I schedule article publication?
Currently, articles publish immediately when approved. Scheduling feature coming soon.

### How do I add co-authors?
Contact admin to add co-authors. Currently each article has one primary author.

### Can I translate articles?
Yes! You can create same article in both languages with appropriate translations.

### How many articles can I create?
Unlimited! Create as many as you want.

### Can I restore a deleted draft?
Deleted drafts cannot be restored. Be careful when deleting.

## Troubleshooting

### Can't log in?
- Check username/email spelling
- Ensure CAPS LOCK is off
- Reset password if forgotten
- Clear browser cache
- Try different browser

### Article won't save?
- Check internet connection
- Refresh page and try again
- Try shorter title/content
- Contact support if persists

### Images not uploading?
- Check file size (max 5MB)
- Supported formats: JPG, PNG, GIF, WebP
- Check internet connection
- Clear browser cache

### Can't find my article?
- Use search feature
- Check filters
- Article may be in draft status
- Check if deleted

### Slow performance?
- Clear browser cache
- Update browser
- Reduce large image files
- Close extra tabs/windows

### Text formatting lost?
- Refresh page
- Avoid pasting from Word
- Use "Paste as Plain Text"
- Try different browser

### Still having issues?
1. **Check FAQ** - Most common issues covered
2. **Contact Support** - Email or chat
3. **Report Bug** - Include details and screenshots
4. **Check Status Page** - See if system issues reported
